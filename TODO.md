# Entregas

- [ ] **Sincronização de favoritos por conta Google:** ao clicar pela primeira vez no coração de um criador ou publicação sem estar logado, apresentar o pedido para entrar com Google; após selecionar e autenticar a conta, salvar o item selecionado no Firestore associado à conta. Com o usuário autenticado, alternar entre adicionar e remover favoritos sem exigir novo login. Os favoritos devem persistir depois de atualizar ou voltar ao site e ser os mesmos em qualquer dispositivo conectado à mesma conta.
- [ ] **Indicador visual e seção Favoritos:** ao favoritar um perfil ou publicação logado, o coração correspondente fica vermelho. Na seção Favoritos, listar perfis e publicações salvos pela conta, separados ou identificáveis pela categoria correta, e refletir remoções em tempo real.
- [x] **Somente Preview, sem publicação pública:** deixar as correções atualizadas e testáveis no Preview da Manus; não acionar publicação permanente nem disponibilizar publicamente, conforme a decisão explícita do usuário. Uma publicação futura exige novo pedido.
- [x] **Motion blur e animações ao rolar:** usar como referência `https://devpbr.vercel.app/`; quando a pessoa rolar, fazer conteúdos e cartões aparecerem com blur de movimento, opacidade progressiva, deslocamento curto e entradas escalonadas, ficando nítidos após entrar na tela. Durante a rolagem aplicar blur sutil e breve. Respeitar `prefers-reduced-motion`.
- [x] **Entrega para testar:** fornecer um `.zip` atualizado do projeto e deixar a versão com as animações no Preview da Manus.
- [x] **Duração estável e busca na timeline:** ao selecionar um vídeo, mostrar uma única duração total correta a partir dos metadados do arquivo; ela não deve aumentar conforme o vídeo toca nem mudar a escala da timeline. Ao arrastar a timeline para outro ponto (por exemplo, o meio), o player deve buscar esse ponto e continuar dali, sem voltar ao início. Manter a escolha do arquivo quando há mais de um vídeo.
- [ ] **Download completo e correto:** ao clicar no botão de download para uma imagem, vídeo, APK ou outro arquivo disponível retornado pela API oficial, iniciar o download do arquivo original com nome e extensão corretos, sem abrir player, página do provedor ou interface intermediária. Corrigir especificamente o fallback de arquivos grandes que redireciona para a origem; nunca salvar HTML/JSON de erro como arquivo de mídia. Se a API não disponibilizar o original (404/403) ou a plataforma/provedor impedir o download direto, informar a falha/limitação em vez de apresentar um download falso.
- [x] **Links externos no post:** quando o texto de uma publicação tiver um link externo (por exemplo, Google Drive), mostrá-lo como opção/cartão em “Arquivos e Downloads”. Para arquivos do Drive com ID extraível e acesso público/autorizado, usar a URL de exportação/download direto em vez da página de visualização; preservar acesso original como alternativa para pastas, documentos nativos ou links que não possam ser convertidos. Continuar suportando links HTML, Markdown e URLs HTTP(S), eliminando duplicatas e ignorando esquemas inseguros.
- [x] **Galerias com muitos arquivos:** em uma publicação com dezenas de imagens, exibir a lista de cada arquivo que a API disponibiliza com o nome, botão de olho para abrir a prévia e botão de download; não mostrar somente a contagem da galeria. Quando a API marcar uma imagem como `preview_only` mas fornecer uma URL temporária de imagem válida, usar essa URL fornecida para preview/download em vez de descartar a imagem ou fabricar um caminho de arquivo.
